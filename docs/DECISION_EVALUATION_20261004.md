2. 先细化六类定义、分类提示和可用证据检查，再按模型分别校准分类置信度与检索支持阈值。校准集/留出集分开，检查明确否定答案、时间限定与真实正例误拒，不在本轮测试题上追求全正收益。
3. 检查结构化facts、原文、FTS与向量的来源对齐及候选覆盖；核验模型只有过滤能力，无法恢复已经遗漏的答案。对两个原话共同失败保留逐题证据再定位。
4. 限制一条检索跨阶段核验的总预算，评估合并重复候选、批处理与热缓存收益；保留原话保护、繁忙回退和熔断。单次接口低于2秒不保证总检索低于2秒。
5. 客户仍自行选模型，也可只启用检索任务。分类、embedding、抽取和索引不应因“增加决策模型”而一并强制接管。当前embedding、抽取与索引实现没有引入决策模型，未获得这三个环节的提速证据；reranker仍保留。

24条分类与60题检索是小规模诊断集，相关家族不是独立生产样本。扩大代表性独立样本能降低估计的不确定性，不能自动提高模型准确率。报告用于下一轮设计和本地优化决策，尚不足以直接给生产更换模型或封版。
